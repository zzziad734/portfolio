About

Security student, hands-on by habit

My journey into cybersecurity started with almost no knowledge of the field. The first time I came across penetration testing, I was curious about how security vulnerabilities were actually discovered and exploited — and that curiosity quickly turned into a passion.

I started learning from the fundamentals, gradually moving into web application security, vulnerability assessment, and hands-on security testing. The more I learned, the more I wanted to understand not just how vulnerabilities work, but how to properly identify, validate, reproduce, and document them.

Today, I focus on Web Application Security and Vulnerability Assessment, using tools such as Burp Suite, Nmap, Gobuster, and Linux to perform authorized security testing.

My approach is practical and evidence-based: understand the application, identify potential weaknesses, validate their impact, and provide clear reports with reproducible evidence and remediation recommendations.
